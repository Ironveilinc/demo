Your morning

The gap between what a calendar says and when the alarm has to go off. A shift at 07:00 has never once meant getting up at 07:00, and these are the minutes in between.

Caffeine

A 16oz Reign is 300 mg. A Ghost Energy is 200. The window is worked out from the dose, so it moves if you change this.

Half-life averages 5 hours in healthy adults but runs anywhere from 1.5 to 9.5 between people. If coffee at 4pm has never cost you a minute, yours is short, and this is where to say so.

Ring goals

Apple makes you pick a Move goal, so nobody here can read it off the watch. Set it and the rings on the Body screen fill against your number instead of your own median.

Alarms

A web page cannot read or set an iPhone alarm. There is no API for it, by Apple's design, and nothing here will pretend otherwise. What it can do is hand the time to a Shortcut, which can.

  1. Shortcuts app, new shortcut, name it exactly what you typed above.
  2. Add Create Alarm, set its time to Shortcut Input, label it Sleep Lab, repeat never.
  3. Save. From then on the Set alarm button on the Plan screen fills it in for you.

If you would rather not build it, Add to calendar on the Plan screen downloads a single event with an alert on it. That gives you a notification rather than an alarm, and needs nothing set up.
